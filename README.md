# SYNENT Task 3 - Netflix Exploratory Data Analysis

## 📌 Project Overview

This project is part of my Data Science Internship at SYNENT Technologies.

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to identify trends, patterns, and useful insights.

## 📊 Dataset

Dataset: Netflix Movies and TV Shows

Source: Kaggle

The dataset contains information about Netflix titles, including:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## 🛠️ Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

## 🔍 Exploratory Data Analysis

The following steps were performed:

1. Loaded the Netflix dataset.
2. Examined the dataset structure.
3. Generated summary statistics.
4. Checked for missing values.
5. Handled selected missing values.
6. Compared Movies and TV Shows.
7. Analyzed the countries with the highest number of titles.
8. Examined content rating distribution.
9. Analyzed Netflix content added over time.
10. Performed correlation analysis on numerical columns.
11. Saved the processed dataset.

## 📈 Visualizations

The following visualizations were created:

- Movies vs TV Shows
- Top 10 Countries by Number of Titles
- Content Rating Distribution
- Netflix Content Added Per Year

## 💡 Key Insights

- Movies represent a larger portion of the dataset than TV Shows.
- Netflix contains titles from many different countries.
- The dataset contains a variety of content ratings.
- The number of titles added over time helps identify the growth of Netflix's content library.
- Visualizations make it easier to identify patterns and trends in the dataset.
